# Мур-мур · маленькие приключения

Уютная игра «3 в ряд» для iPhone и браузера. 15 уровней, три главы, Лайм и Текила, именные умения и альбом наград. Без рекламы, таймера, платных жизней и серверной части.

**Играть:** https://koffing-test.github.io/cat-match/

## Что есть

- Свайпы, выбор двумя касаниями и управление кнопками с клавиатуры.
- Цели: собрать рыбки, убрать нитки с клеток, провести мышек вниз.
- Четыре в ряд создают усилитель, пять — радужную фишку, пересечение — взрыв. Усилители можно соединять.
- Лайм: «Активация мурчания» — +3 хода и мягкий звук при включённом аудио. Текила (старшая): «Королева квартиры» — очистка выбранного ряда и столбца. Обе: «Вечерние бесоебства» — 12 случайных фишек после шести удачных ходов. Каждое умение один раз за уровень, без расхода хода.
- Три награды за главы: Лайм, Текила и обе вместе. Вместо фото по умолчанию — SVG-иллюстрации. В альбоме можно заранее выбрать личные фотографии прямо на устройстве; закрытые награды не показывают загруженные снимки до прохождения главы.
- Нежная розовая тема, мобильная вёрстка и анимации именных умений.
- Автосохранение завершённых уровней и звёзд в localStorage. Незавершённый уровень начинается заново после закрытия. Экспорт/импорт прогресса в «Как играть».
- PWA, локальные шрифты, офлайн-режим после полной первой загрузки и установки service worker.

## Установка на iPhone

Открыть ссылку в Safari → «Поделиться» → «На экран “Домой”». Включить «Открывать как веб-приложение», если такой переключатель есть. Первую загрузку выполнить с интернетом. Очистка данных сайта может удалить прогресс; для переноса есть резервная копия.

## Разработка

Нужны Python 3 для локального сервера и Node.js 22+ для тестов. Сборки и npm-зависимостей нет.

```sh
python3 -m http.server 4173
npm test
node tests/balance.mjs
```

- `engine.js` — правила, каскады, цели, спецфишки, проверка доступных ходов.
- `app.js` — экраны, pointer-управление, анимации, сохранения, звук.
- `photos.js` — локальные фото, подготовка изображений, IndexedDB и перенос альбома.
- `art.js`, `assets/` — собственные иллюстрации, иконки и открытые шрифты.
- `tests/engine.test.js` — стартовые поля, спецфишки, цели, партии и инварианты.
- `tests/balance.mjs` — оценка баланса жадным игроком на 100 seed для каждого уровня. Это диагностическая симуляция, не оценка человеческой вероятности победы.

## Публикация и обновления

GitHub Pages публикует корень ветки `main`. `.nojekyll` отключает Jekyll. При изменении офлайн-файлов обновляйте имя `CACHE` в `sw.js`; новая версия активируется после закрытия старых вкладок. Список `FILES` должен включать новые обязательные ресурсы. HTML использует относительные пути для размещения в `/cat-match/`.

## Фотографии в галерее

На iPhone, где будут играть: «Наш альбом» → «Добавить фотографии» → выбрать снимки Лайм, Текилы и обеих девочек. Подготовить фото можно до прохождения уровней. Награды откроются после 5, 10 и 15 уровней; управление альбомом не меняет прогресс игры.

Снимки не отправляются на сервер и не попадают в GitHub. Они хранятся в IndexedDB на этом устройстве, отдельно от прогресса. Картинки автоматически уменьшаются до 1600 px по длинной стороне и заново кодируются в JPEG без исходных метаданных. Максимальный входной размер 25 МБ. Надёжнее всего JPEG/PNG/WebP; HEIC/HEIF зависит от поддержки декодирования браузером. При ошибке используйте JPEG. Для совместимости с Safari в IndexedDB хранятся байты, а не file-backed Blob.

«Скачать копию альбома» создаёт JSON с фотографиями. Его можно передать на iPhone жены и выбрать «Загрузить копию альбома». Импорт заменяет фото соответствующих глав, не меняя победы. Сохранение прогресса и сохранение фотоальбома — отдельные операции. Очистка данных сайта может удалить и фото, и прогресс. Данные Safari и установленной веб-игры могут храниться отдельно: лучше добавлять снимки из иконки игры после установки.

Сам сайт на GitHub Pages публичный. Добавленные через интерфейс фотографии доступны только локально; это не парольная защита от других пользователей того же устройства. Встроенные в репозиторий изображения были бы публичны, поэтому личные снимки туда не добавляются.

## Проверка версии 1

12 автотестов проверяют новые умения, их одноразовость и заряд, а также 1 500 стартовых полей и 300 полных партий. В Chromium и WebKit на viewport 393 × 852 проверены вёрстка, свайп, неверный ход без расхода, победа, сохранение, именные умения, фотоальбом и повторная загрузка без сети. Загрузка, уменьшение, экспорт/импорт фотографий и их сохранение офлайн проверяются отдельно в Chromium и WebKit. На физическом iPhone проверка ещё не выполнена.

## Лицензии ресурсов

SVG-иллюстрации и звуки созданы для этого проекта. Comfortaa и Manrope распространяются по SIL Open Font License; тексты лицензий находятся в `assets/fonts/`. Внешние игровые шаблоны и Phaser не используются: для этой небольшой версии достаточно JavaScript, CSS и SVG.
